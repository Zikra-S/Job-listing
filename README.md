# Job Listings with Filtering

A responsive job listings website built with **HTML, Tailwind CSS, TypeScript, and Vite**.

Browse job listings and filter them by role, level, programming language, or tool. Multiple filters can be applied simultaneously.

## ✨ Features

- Display job listings dynamically
- Filter jobs by role, level, language, and tools
- Apply multiple filters simultaneously
- Remove individual filters
- Clear all active filters
- Responsive design for desktop and mobile
- Interactive hover states

## 🛠️ Built With

- HTML5
- Tailwind CSS
- TypeScript
- Vite

## 🎯 Project

This project was built as a frontend challenge to practice responsive UI development and interactive filtering functionality.
